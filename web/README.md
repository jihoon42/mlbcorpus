# Play-by-Word

경기 하나를 고르면 그 경기를 적은 실제 문장(기록 문장, 하이라이트 캡션, 리캡 기사)으로 야구 영어와 스페인어를 공부하는 페이지다. 서버 없이 브라우저에서만 돈다.

## 여는 법

1. `index.html`을 브라우저로 연다(더블클릭). 같은 폴더에 `lexicon.js`가 있어야 한다.
2. 열리지 않거나 경기 목록이 뜨지 않으면 이 폴더에서 `python3 -m http.server 8000`을 실행하고 `http://localhost:8000`으로 들어간다.

문장은 MLB Stats API에서 그때그때 받아 오므로 인터넷 연결이 필요하다. 처음 열면 2026년 10월 28일(월드시리즈 5차전)이 골라져 있고, 주소 뒤에 `?date=2026-09-17`처럼 붙이면 그 날짜로 열린다.

## 화면

- 장면: 하이라이트 영상이 붙은 타석마다 기록 문장과 캡션을 영어와 스페인어로 보여 준다. 밑줄 친 표현을 누르면 뜻, 쓰이는 장면, 타구 수치, 바꿔 쓸 말, 같이 쓰는 말, 다른 언어의 표현이 카드로 나온다. 파란 밑줄은 영어, 붉은 밑줄은 스페인어, 점선은 아직 한국어 뜻을 달지 못한 말이다.
- 퀴즈: 그 경기 문장에서 주어 바로 뒤의 동사를 가리고 넷 가운데 고르게 한다.
- 기사 읽기: 그 경기의 리캡 기사. 앞의 장면에서 본 표현을 노랗게 칠한다.
- 맞대결: 선수 한 명을 가운데 두고, 캡션에서 그 선수에게 무언가를 한 선수(왼쪽, 주어)와 그 선수가 무언가를 한 선수(오른쪽, 목적어)를 동사와 함께 잇는다. 이름을 누르면 그 선수로 옮겨 가고, 동사를 누르면 그 타석의 기록 문장과 캡션이 영어와 스페인어로 나온다. 경기를 고르지 않아도 쓸 수 있고, 장면 화면의 선수 이름을 눌러도 들어온다.

"외웠어요"를 누른 표현은 뜻을 숨긴다. 이 기록은 브라우저(localStorage)에만 남는다.

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 화면과 동작 전부. 외부 라이브러리를 쓰지 않는다 |
| `lexicon.js` | 표현 사전. `index.html`이 읽는 파일 |
| `lexicon.json` | 같은 사전의 JSON판 |
| `relations.js` | 맞대결 자료. 맞대결 화면을 처음 열 때 읽는다 |

사전은 `analysis/lex_lexicon.py`가 만든다. 표현과 통계만 들어 있고 기사나 캡션의 원문은 없다. 한국어 뜻은 `analysis/lex_gloss_ko.tsv`에 있고, 줄을 더한 뒤 아래 명령을 다시 돌리면 사전에 들어간다.

```bash
python3 analysis/lex_lexicon.py
python3 analysis/lex_relations.py   # 맞대결 자료. 사전을 만든 뒤에 돌린다
```

맞대결 자료에도 선수 이름, 동사, 횟수, 타석 번호만 있고 문장은 없다.

## 브라우저가 부르는 주소

| 주소 | 받는 것 |
|---|---|
| `v1/schedule?sportId=1&date=YYYY-MM-DD` | 그날 경기 목록 |
| `v1.1/game/{pk}/feed/live` | 타석, 영어 기록 문장, 타구 수치, 선수 이름 |
| `v1/game/{pk}/playByPlay?language=es&fields=...` | 스페인어 기록 문장 |
| `v1/game/{pk}/content`, `content?language=es` | 캡션과 리캡 기사 |
| `v1/game/{pk}/playByPlay?fields=...` | 맞대결에서 쓰는 영어 기록 문장 |
| `v1/schedule?sportId=1&gamePk={pk}` | 맞대결에서 쓰는 경기 날짜와 팀 |

주소 뒤에 `?tab=rel&player=660271`을 붙이면 맞대결 화면이 그 선수로 바로 열린다. `?api=http://localhost:8765/api`처럼 붙이면 API 주소를 바꿀 수 있다. 점검할 때 받아 둔 응답을 돌려주는 임시 서버를 붙이는 용도다.

## 올릴 때

정적 파일 네 개라 어느 정적 호스팅에 올려도 돈다. 바깥으로 나가는 요청을 막는 곳에서는 돌지 않는다. 문장의 저작권은 MLB에 있으므로 페이지는 문장을 저장하지 않고 받은 자리에서 보여 주기만 한다.

## 알려진 한계

- 한국어 뜻은 표현마다 하나이고 문맥에 따라 바뀌지 않는다(strike out, walk, score만 예외).
- 스페인어 표현에는 묶음과 바꿔 쓸 말이 아직 없다.
- 리캡 기사는 사전을 만든 글과 종류가 달라서 밑줄이 덜 붙는다.
- 캡션이 붙지 않은 경기는 득점 장면 위주로 보여 준다.
- 맞대결은 2026년 8월까지의 캡션에서 뽑았고, 같은 두 선수가 되풀이해 나오는 경우는 드물다. 삼진이 60%를 차지한다.
